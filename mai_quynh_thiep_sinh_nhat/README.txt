# THIỆP SINH NHẬT MAI QUỲNH

## 1. Chạy bằng VS Code
Mở thư mục này bằng Visual Studio Code.
Cài extension **Live Server**, sau đó bấm chuột phải vào `index.html` → **Open with Live Server**.

## 2. Thay ảnh
Đặt ảnh của Mai Quỳnh vào:
`images/mai-quynh.jpg`

## 3. Thêm nhạc
Đặt file MP3 vào:
`music/birthday.mp3`

## 4. Tên khách mời tự động theo link
Trang đọc tên từ tham số `to`.

Ví dụ:
`index.html?to=Nguyễn Văn An`

Có thể dùng:
`index.html?to=Nguyễn%20Văn%20An`

Nếu host website, mỗi người có thể có một link riêng:
`https://ten-website.com/?to=Nguyễn%20Văn%20An`

## 5. Chỉnh giờ/địa điểm
Mở `index.html` và sửa:
- `19:00`
- `Địa điểm tổ chức`

Trong `script.js`, thời gian đếm ngược hiện là:
`2026-09-13T19:00:00+07:00`
